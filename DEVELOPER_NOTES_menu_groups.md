# Developer Notes — Menu Groups

## 1. How the menu groups are formed

The site menu is generated by:

layouts/_partials/docs/menu-filetree.html

The template builds groups from Hugo section pages.

Each group has:
- a list of section slugs;
- a rank that determines the group's position;
- a rendering block that displays matching sections.

For the `Series & Projects` group, the relevant list is:

$seriesProjectsSlugs

A section is included in the group when its slug is present in this list.

---

## 2. Related files

### Menu structure

layouts/_partials/docs/menu-filetree.html

This is the only file that needs to be changed to add a new series to
`Series & Projects`.

### Series content

content/uk/docs/<slug>/
content/en/docs/<slug>/
content/pt/docs/<slug>/
content/ru/docs/<slug>/

Each language version is a Hugo section.

The menu template uses:

path.Base $page.File.Dir

to obtain the section slug.

---

## 3. Required condition

For a series to appear in `Series & Projects`:

1. It must be a Hugo section under `content/<language>/docs/`.
2. Its directory name must produce the intended slug.
3. That slug must be included in `$seriesProjectsSlugs`.
4. The section must be available in the language version being displayed.

No separate menu markup is required for the new series.

---

##  4. Adding a new series

###  Step 1 — Create the language versions

Create:

content/uk/docs/<slug>/
content/en/docs/<slug>/
content/pt/docs/<slug>/
content/ru/docs/<slug>/

with `_index.md` in each required language.

### Step 2 — Determine the slug

The slug is the section directory name.

Example:

events-that-reveal-the-system

### Step 3 — Add the slug to `$seriesProjectsSlugs`

Edit:

layouts/_partials/docs/menu-filetree.html

and add:

"events-that-reveal-the-system"

to the `$seriesProjectsSlugs` list.

### Step 4 — Build and verify

Run:

hugo

Then run:

hugo server

and verify that the series appears under:

Series & Projects

### Step 5 — Publish

Check:

git diff --check
git status --short

Stage only the intended files, create a commit, and push.

# 💎 Code of Conduct — Pivtorak.Studio  
Resonance → Form → Responsibility  

## 1. Non-negotiable Quality  

Quality is a constant.    
If resonance is not achieved, the system does not launch.  

We do not fix errors.    
We design systems where error is structurally impossible.  

## 2. Presence as a Standard  

Appearance, language, and environment are the first drafts of the work.  

Flawlessness from the first attempt   
is discipline of thought expressed through form.  

## 3. Foundation First  

The foundation defines everything.  

We invest in structure, not in effect.    
Accents only amplify what is already strong.  

## 4. Non-delegated Responsibility  

Advice may be collective.    
Decisions are always personal.  

Every project carries a signature.    
And that signature carries responsibility.

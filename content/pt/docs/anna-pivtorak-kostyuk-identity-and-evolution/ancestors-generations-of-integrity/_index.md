# Ancestrais: Gerações de Integridade

*Nem tudo o que forma um sistema pode ser diretamente identificado.*

Esta secção é dedicada aos antepassados — não como figuras individuais,  
mas como um **campo de linhagem** no qual o pensamento se forma.

Não se trata de biografias,  
mas do que é transmitido para além das palavras:  
- a perceção do limite entre o aceitável e o inaceitável  
- a atitude perante o trabalho  
- a capacidade de suportar carga  
- a integridade interna  

Estas qualidades nem sempre são conscientes,  
mas definem:  
- como as decisões são tomadas  
- o que é considerado correto  
- onde se estabelece o limite  

Não é memória no sentido direto.  
É uma **estrutura que existe antes da experiência individual**.

Algumas figuras podem ser nomeadas.  
Mas a maior parte da influência permanece sem nome.

Esta secção não documenta histórias,  
mas a **presença das gerações no pensamento**.

# Truques de SEO

*Pequenos detalhes técnicos podem mudar aquilo que um website realmente faz.*

Truques de SEO é uma série de investigações práticas de SEO técnico, construídas a partir de perguntas reais, resultados inesperados e das evidências necessárias para os compreender.

Esta não é uma coleção de dicas genéricas de SEO.

Cada investigação começa com uma pergunta específica:

**O que deveria acontecer?  
O que acontece realmente?  
Porque existe essa diferença?**

Depois seguimos as evidências — através dos ficheiros de origem, configuração, templates, resultados gerados, respostas HTTP e website em produção — até a causa técnica ficar clara.

## Como é investigado um Truque de SEO

Uma investigação típica segue este percurso:

**Pergunta → Verificação → Evidência → Causa → Correção → Validação**

O princípio de validação é especialmente importante:

**Source → Generated Build → Live**

A origem mostra o que pedimos ao sistema para fazer.  
O build gerado mostra o que o sistema realmente produziu.  
O website em produção mostra aquilo que os visitantes e os crawlers dos motores de pesquisa podem realmente receber.

Um ficheiro pode existir e, mesmo assim, estar errado.  
Uma configuração pode estar ativa e, ainda assim, produzir um resultado inesperado.  
Um build concluído com sucesso não significa automaticamente que o website esteja correto.

É aí que começa a parte interessante.

## O que encontrará aqui

Cada Truque de SEO centra-se numa questão ou problema técnico claramente definido.

Consoante o caso, uma investigação pode analisar:

- crawling e capacidade de rastreamento;
- indexação e descoberta;
- comportamento do robots.txt e do sitemap;
- configuração e templates do Hugo;
- ficheiros gerados e resultados do build;
- URLs, redirecionamentos e sinais canónicos;
- implementação de SEO técnico;
- interações inesperadas entre componentes do website;
- a diferença entre aquilo que a origem define e aquilo que o website realmente entrega.

Sempre que possível, a investigação apresenta a própria evidência: ficheiros reais, comandos, configuração, resultados gerados, screenshots, diagramas e verificações em produção.

**Não aceite apenas a regra. Siga as evidências.**

**Truques de SEO é sobre o momento em que “deveria funcionar” já não é suficiente.**

Verifique.  
Siga o rasto.  
Compreenda.  
Valide.

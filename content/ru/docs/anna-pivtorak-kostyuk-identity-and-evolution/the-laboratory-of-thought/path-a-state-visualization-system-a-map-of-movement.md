# Path: Система визуализации состояний. Карта движения    
_Ясность сильнее мотивации_   

## Path   

**Path** — это не список дел. Это структурная карта движения, где каждый элемент существует не в бинарной логике «сделано/не сделано», а в динамике трёх состояний.   

Большинство систем планирования смешивают намерение и завершение, что создает давление и ощущение хаоса. **Path** разделяет их, заменяя мотивацию ясностью.   

## Три состояния элемента:  

- **◯ — Определено (Defined):** Задача выделена в пространстве. Намерение сформировано.   
- **⊙ — В процессе (In Progress):** Действие продолжается. Процесс запущен, энергия инвестирована.   
- **⨁ — Верифицировано (Verified):** Результат подтвержден внешним миром. Отчет принят, документ получен, экзамен сдан.   

## Философия:   

Вы не подталкиваете себя силой воли. Вы просто видите свою позицию. Здесь нет дедлайнов, вызывающих тревогу, — есть только положение на карте.   

- **Path** показывает структуру и направление.   
- **Done.** (Факт) подтверждает реальность движения.

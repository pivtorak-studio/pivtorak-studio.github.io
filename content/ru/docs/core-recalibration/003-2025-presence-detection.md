# Обнаружение Присутствия

_Осознанность — это не тишина._
_Это ритм — распознанный._

Не поиск покоя. Не режим паузы.

А точное считывание момента, в котором тело, время и движение соединены в систему.

Пульс — не мешает.
Уведомления — не прерывают.
Дыхание — не сбивается.
Каждый сигнал — индикатор.
Каждое колебание — подтверждение процесса.

Сканирование завершено.
Сигнал активен.
Пространство отвечает.

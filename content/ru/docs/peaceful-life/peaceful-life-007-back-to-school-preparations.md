

# 🧒🎒📝 Подготовка к школе

_Когда мир даёт место для карандашей — а не для страха

Август — ещё лето.  
Но в мыслях детей — уже школа.  
Они не боятся. Потому что знают: там будет безопасно.

Собираем новые вещи:  
ручки, тетради, футболки, рюкзаки.  
Всё уже готово — без страха, без давления.  
Футболка — не для строя. А для удобства.  
Рюкзак — не для побега. А чтобы нести туда мечты.

Школа в мирной стране — не наказание.  
Не «гражданский долг».  
Это пространство роста.

И каждый ребёнок имеет право готовиться к школе  
не со слезами, а с ожиданием.

**Alt-text:**  
Иллюстрация с двумя улыбающимися детьми, которые рассматривают новые школьные вещи. Девочка и мальчик в простых футболках собирают канцтовары. Атмосфера — радостная, лёгкая. Настроение — предвкушение учебного года без давления. Просто — жизнь.

**🪙 Pivtorak.Studio — Формула трансформации**

# 💎 Критерии отбора проектов — Pivtorak.Studio  

Соответствие → Резонанс → Реализация  

**Критерии резонанса**  

## 1. Соответствие масштаба  
Проект должен выходить за рамки локальной задачи.  
Он должен иметь потенциал влияния на систему, а не только решать отдельную проблему.  

## 2. Чёткость запроса  
Запрос должен быть сформулирован.  
Даже если решение ещё не найдено, направление должно быть понятно.  

## 3. Готовность к точности  
Проект предполагает работу без упрощений.  
Внимание к деталям — часть процесса, а не дополнительная опция.  

## 4. Открытость к структуре  
Система может менять форму проекта.  
Результат не задаётся заранее — он формируется в процессе.  

## 5. Совпадение ценностей  
Решения принимаются на основе качества, а не скорости или внешнего эффекта.  

## 6. Присутствие в процессе  
Проект требует вовлечённости.  
Результат формируется через взаимодействие, а не через передачу задачи.

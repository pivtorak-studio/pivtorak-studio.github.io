# ⊞ Матрица Завершённости Сайта

Матрица Завершённости Сайта — это рабочая панель, предназначенная для отслеживания состояния материалов Pivtorak.Studio.

Её задача не заменить редакционный процесс, а предоставить наглядный обзор того, какие материалы уже достигли необходимого уровня завершённости, а какие ещё требуют внимания.

Матрица объединяет данные, автоматически собираемые из Front Matter, и результаты ручной проверки, выполняемой в процессе публикации и сопровождения материалов.

Текущая версия отслеживает четыре направления:

## Дата

Дата публикации страницы.

## Заголовок

Название страницы в текущей языковой версии.

## SEO

Страница содержит основные элементы, необходимые для долгосрочной видимости и обнаружения:

- изображение;  
- alt-текст;  
- canonical URL;  
- JSON-LD (Schema.org);  
- интеграцию в Timeline.  

### Распространение

Страница подготовлена для публикации или распространения через внешние платформы:

- Instagram;  
- Facebook;  
- Threads;  
- Pinterest;  
- LinkedIn;  
- X;  
- YouTube;  
- TikTok.  

### Поиск

Текущий статус индексации страницы.

Обозначения:

- ⚪ Не начато  
- 🟡 В процессе  
- 🟢 Завершено  

Помимо этих показателей система автоматически собирает метаданные из Front Matter, включая идентификаторы, языковые версии, информацию о сериях, даты публикации, статус завершённости и признаки избранных материалов.

Матрица является частью инициативы The Movement Matrix и служит развивающимся инструментом для поддержки многоязычного архива знаний.

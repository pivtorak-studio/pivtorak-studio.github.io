# 🌱☀️ Мирне Життя

#PeacefulLife — це серія робіт про прості речі, які створюють мирне життя.

Дитинство без страху.
Природа без руйнування.
Праця без приниження.
Домівка без втрати.
Турбота без провини.

Кожна робота показує не героїв війни чи боротьби, а умови, заради яких варто будувати майбутнє.

Це серія про права людини, права дітей, права природи та про цінність звичайного життя.

Іноді мир починається не з великих рішень, а з теплого дому, чашки чаю, осіннього лісу або дитячого малюнка.

Саме з таких моментів складається #PeacefulLife.

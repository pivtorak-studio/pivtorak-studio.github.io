# ⊞ Матриця Руху

Матриця Руху — це експериментальна система, створена в межах Pivtorak.Studio для відстеження розвитку статей, серій, перекладів, метаданих та процесів публікації.

Те, що починалося як звичайна електронна таблиця, поступово дозволило побачити закономірності, прогалини та можливості для вдосконалення. У міру розширення архіву різними мовами та платформами стало важливо розуміти не лише те, що вже створено, але й те, що ще потребує уваги.

Матриця є живою картою проєкту.

Вона допомагає відстежувати:

- опубліковані статті;
    
- мовні версії;
    
- розвиток серій;
    
- повноту метаданих;
    
- зображення та описи;
    
- структуровані дані (Schema.org);
    
- інтеграцію в Timeline;
    
- статус публікації та індексації.
    

Матриця є одночасно практичним інструментом і експериментом зі створення систем для незалежних досліджень, творчої роботи та довготривалого збереження знань.

Її структура буде змінюватися та розвиватися разом із самим проєктом.
